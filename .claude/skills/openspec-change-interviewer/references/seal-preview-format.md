# Optional source preview

An existing change-local seal-preview.md may summarize confirmed source scope,
retention, unresolved business choices and acceptance anchors. It is advisory
source review, not an installation marker, receipt, runtime PASS or second ledger.
Do not create a preview when the current task does not require one.

Read current proposal/design/tasks and derived index. Record source anchors and
byte digests only as review evidence; never hand-fill controller binding IDs.
Source changes invalidate old previews. Reuse user authority for the current
bounded repair; do not ask the user to approve a retired lifecycle.
