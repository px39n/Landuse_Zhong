# portable unblock report.v2

Compare expected and observed outcomes with current source/evidence anchors.
Return receipt_ref plus result using the current action schema. Diagnostic findings
belong in evidence_refs under approved roots; result contains status, changed_files,
evidence_refs, blockers, risks and skipped_checks. The controller derives binding
IDs. Do not add manual identities or an alternate lifecycle to this report.

Name one falsifiable root cause, minimal proposed correction and a verifying check.
Distinguish missing evidence, execution failure and DEVIATED direction. Preserve
budget_lineage_id and actual usage. Diagnosis grants no implementation, redispatch,
scope expansion or PASS; current controller authority decides any repair.
Historical raw reports remain evidence, without an executable old reader contract.
