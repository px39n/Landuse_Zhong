controller's admitted work; do not rerun census or construct another scheduler.

and the smallest relevant check. Return a suggested semantic role, reason and
anchors; this recommendation grants neither dispatch nor write authority.

host driver uses actual tools with default/inherited available model unless the
user requested a model. Keep upstream 21-role provenance without executing its
